# GaussRoom 项目 PRD

本文档定义当前产品的行为和验收要求。基准提交为 `52f94dc`，核对日期为 2026-11-04。实现细节见[代码设计](CODE_DESIGN.md)，使用步骤见 [README](../README.md)。

## 1. 产品定位

GaussRoom 帮助用户把室内照片或 iPhone LiDAR 扫描转为三维成果。Windows 工作台生成高斯场景。手机网页负责采集入口、上传、任务状态和在线查看。原生 iPhone APP 另外提供离线网格扫描、编辑、测距和导出。

主要用户包括：

- 房间记录者：拍摄一个房间或相邻房间，保存并查看空间。
- 电脑操作员：维护本机环境，运行重建，检查失败原因及模型质量。
- 项目维护者：定位数据与算法问题，保留实验结果，继续开发。

成功的结果应满足以下条件：用户知道如何提交数据；任务状态可以解释；不合格几何不能直接训练；旧成果不会因一次失败被覆盖；用户可以区分模型导出与质量验收完成。

项目不承诺任意照片都能成功重建，也不承诺达到工程测量精度。

## 2. 产品范围与默认值

### 2.1 当前范围

- 支持 Windows 本地工作台和局域网手机网关。
- 支持普通照片的 COLMAP 重建和固定 ARKit 标定的扫描重建。
- 支持一次连续 LiDAR 会话中的单房间与相邻房间。
- 支持可追溯的人工辅助、区域提取、局部位置修正和历史结果查看。
- 支持浏览器高斯漫游与原生 APP 本地网格查看。

### 2.2 首版边界

- 不提供 Android 原生扫描 APP、Android 深度采集或手机本地高斯训练。
- 不提供云端训练、多用户账号体系、公共互联网部署或多作业队列。
- 不提供网页实时取景、视频抽帧、跨 LiDAR 会话拼接、RoomPlan 户型或 TrueDepth 小物体扫描。
- 不交付 App Store 发布、云端 Mac 构建或可安装 IPA。
- 不把桌面普通照片的模型单位直接当作米。

### 2.3 默认设置

桌面服务默认监听 `127.0.0.1:8123`。手机网关默认关闭，启用后使用 `8124`。手机照片默认训练档位为 `standard`。照片项目默认使用 `SIMPLE_RADIAL`、增量式重建和标准特征档位。LiDAR 项目使用固定的逐帧 `PINHOLE` 标定。

上传及几何检查的精确限制以[接口与格式契约](CODE_DESIGN.md#http-api)为准。本文中的最低输入条件不是重建成功条件。

## 3. 用户流程与功能要求

每个需求包含操作条件、预期结果、异常处理和可检查的验收项。除专门说明外，“实现”表示源码中存在相应行为；它不表示已通过全部设备验收。

### 3.1 项目与电脑照片

**GR-P01：创建和读取项目。** 用户提供项目名、至少两张支持图片的源目录和有效训练档位。系统创建独立项目并显示配置、步骤和状态。目录无效、图片不足或档位无效时返回原因。验收时检查新项目、列表、刷新及服务重启后的读取。

**GR-P02：保存原始输入。** 桌面源照片只读，预处理写工作副本。手机照片提交后复制到新项目。LiDAR 导入保存完整原始扫描。验收时比较源文件，并确认各项目的数据互不覆盖。

**GR-P03：修改重建设置。** 用户可调整普通照片项目的训练档位、相机模型、特征档位及重建方式。影响输入或几何的修改使相应后续步骤失效，并保留累计执行时间。LiDAR 项目不允许改为普通相机模型或自由位姿流程。验收时检查状态失效、重试入口和旧结果保留。

**GR-P04：删除电脑项目。** 用户确认删除后，系统删除项目内部数据和历史结果。正在运行的项目不能删除。外部源照片保留。验收时检查运行中拒绝、删除目标及无关项目不变。

### 3.2 手机照片网页

**GR-M01：连接电脑。** 电脑启用网关后显示局域网地址和短期配对码。手机提交有效配对码后获得设备令牌。过期、错误或尝试过多时给出错误。电脑可撤销设备。验收时检查未配对、过期、限流、设备隔离及撤销后访问。

**GR-M02：创建上传批次。** 用户填写名称并选择档位，默认 `standard`。系统分配批次 ID。批次属于当前设备。验收时检查创建、列表、单批次读取及其他设备不可见。

**GR-M03：使用系统拍照与相册。** 网页提供拍照和批量选图入口。无法启动相机时，提示先使用系统相机，再选择相册。验收需要分别使用 iPhone Safari 与安卓 Chrome；桌面模拟不能替代该项。

**GR-M04：逐张上传和校验。** 系统分配文件 ID，接收单张二进制数据，计算 SHA256，并检查格式、完整解码和尺寸。JPEG、PNG 为基本格式。HEIC/HEIF 必须先通过服务器解码探测。错误照片不得进入就绪集合。

**GR-M05：去重与容量限制。** 默认单张不超过 64 MiB，每批不超过 500 张、4 GiB。不同文件名不能覆盖已有文件。相同字节内容标记为重复，不增加有效照片数量。重复文件条目仍计入批次容量预留。验收包括同名异内容、同内容异名称、损坏和超限。

**GR-M06：上传恢复。** 成功照片保留在电脑。刷新后恢复批次和成功记录。浏览器不能恢复未上传文件的访问权限，用户须重新选择。失败时重传当前整张照片。验收包括网络中断、服务重启、当前文件重试和重复点击。

**GR-M07：紧凑照片列表。** 默认最多预览 6 项；展开后每页最多 12 项。支持全部、待处理和已完成筛选。当前上传和失败项优先展示。筛选或分页不得改变完整批次的提交判定。验收使用 500 项批次元数据检查渲染数量和翻页。

**GR-M08：提交创建项目。** 批次至少有两张不同哈希、完整解码且长边不少于 1,000 像素的就绪照片。存在待传、上传中或失败项时禁止提交。提交前再次核对文件哈希。重复提交返回同一项目。中断后依恢复记录继续处理，不发布未完成的项目。

**GR-M09：明确启动重建。** 提交完成只创建项目。用户点击“开始重建”才启动电脑作业。若计算槽被占用，显示原因，不自动排队。手机显示阶段、进度、累计时间和质量状态。

**GR-M10：删除批次或项目。** 未提交时显示“删除批次”；已提交时显示“删除项目”。确认弹窗显示名称和无法撤销提示。运行中禁止删除。失败时保留删除记录和重试入口。成功后清除当前批次的本地界面状态，保留配对信息。验收包括取消、成功、失败重试、重启恢复和跨设备拒绝。

手机删除入口仅操作当前设备的普通照片批次及其关联项目。它不删除手机相册，也不删除原生 APP 的本地扫描。

### 3.3 原生 iPhone LiDAR

**GR-L01：检测设备能力。** 开始扫描前检查网格重建和场景深度接口。设备不支持时停止扫描启动并提示原因。目标系统为 iOS 17 及以上，目标设备为 iPhone。

**GR-L02：记录同帧数据。** 关键帧的图像、深度、置信度、内参、位姿和时间来自同一 ARFrame。图像保留传感器方向。串行写入器只允许一个关键帧包在途。验收包括帧关系、文件尺寸、字节布局和内存观察。

**GR-L03：暂停与保存。** 手动暂停、切后台、温度过高、存储或写入失败时保存已有数据并暂停或结束。当前实现对非正常跟踪停止接纳关键帧；会话中断或失败结束扫描。恢复同一会话时不重置世界坐标。验收必须覆盖锁屏、来电、后台、暂停继续和新会话隔离。

**GR-L04：本地网格编辑。** 支持模型旋转、平移、缩放、范围裁剪、撤销裁剪和两点测距。测距显示米并标为估算。裁剪保留三个顶点均在范围内的面，不切分边界三角形。原始网格与关键帧保持不变。

**GR-L05：彩色 OBJ 导出。** 系统根据图像视角和深度遮挡选择纹理，生成 OBJ、MTL 和使用的 JPEG 纹理。没有可靠图像的表面使用中性色。验收需在独立模型工具检查材质和纹理，并检查遮挡、裁剪与无纹理面。

**GR-L06：完整扫描包。** 至少两张不同关键帧后，导出 `.gaussroom.zip`。包内包含清单、逐帧数据、网格、编辑记录和文件 SHA256。电脑联网提交和离线导入使用相同校验器。格式不支持、文件损坏或非法路径时拒绝。

**GR-L07：电脑增强与在线查看。** APP 配对电脑，上传完整扫描包；支持按服务器确认偏移续传。用户点击电脑增强后启动训练。APP 用 WKWebView 打开同一高斯查看器。电脑输入使用完整原始扫描，忽略手机网格裁剪。

当前原生上传入口要求保留 `<扫描 UUID>.gaussroom.zip` 文件名和对应的本机原始扫描。改名包或来自其他手机的有效包使用 Windows 离线导入。验收需区分原生选包限制与服务器扫描格式校验。

### 3.4 重建与人工辅助

**GR-R01：执行七阶段流程。** 按 prepare、features、match、sparse、gate、undistort、train 顺序运行。外部命令失败、超时或取消时停止相关作业，记录日志，不将未验证输出标为成功。

**GR-R02：统一几何门禁。** 普通照片和 LiDAR 项目均检查注册率、重投影误差、点数及真实三维点观察形成的连接。失败后不能直接跳到训练。独立区域可以复制为新项目重新检查，并标注整体布局未验证。

**GR-R03：使用真实观察。** 普通照片通过匹配恢复位姿。LiDAR 项目保持 ARKit 相机位姿和逐帧内参，使用匹配照片观察三角化和优化三维点。不能将网格顶点伪装为照片轨迹。深度只用于误差复核和诊断。

**GR-R04：等待人工补充。** 模型分裂、覆盖未知或用户请求复查时，系统释放计算槽并显示问题。用户可保存“是、不是、不知道”、共同物体、对应点和覆盖判断。保存回答不启动计算。旧版本提交返回冲突，不能覆盖新答案。

**GR-R05：辅助求解。** 用户点击继续后，系统检查回答修订和输入指纹。区域连接至少需要满足配置中的共同点、视角、视差和分布要求。房间名称、关系标签和未经验证的尺寸不能直接生成连接证明。

**GR-R06：局部位置修正。** 用户明确选择修正范围和固定参照。系统基于真实共同点重算选定区域，固定范围外位姿，并重新检查原有连接。观察不足或改善不够时保留原有模型，给出缺失原因。

**GR-R07：增加照片与复用资料。** 用户明确选择来源和资料后才执行。新增照片复制到项目内，同内容去重。同名异内容独立保存。只在照片内容、工作方向和尺寸匹配时复用坐标；不直接复用相机位姿或通过结论。

人工几何求解、局部位置修正和追加普通照片适用于 `photos`。`arkit_scan` 保持固定采集标定，拒绝这些几何或输入修改。位置、连接有误时应重新扫描并导入新的完整包；仅确认区域覆盖可重新执行门禁。

**GR-R08：保留历史尝试。** 重跑保存独立输入快照、数据库、稀疏模型、日志和训练输出。新几何通过检查后才更新当前采用的尝试。失败、取消或回答改变时保留历史结果。历史模型不能代替当前模型完成画面检查。

**GR-R09：检查训练数据来源。** 去畸变数据绑定模型和数据签名。直接重试训练时重新核对。模型、数据、档位、检查点或输出时间关系不匹配时拒绝恢复。恢复载入模型参数并重新初始化优化器，不能称为完整优化器状态续跑。

**GR-R10：计算实际执行时间。** 累计每个阶段的执行时间，包含重试与稀疏阶段内的校准。暂停、等待补充和作业间隔不增加时间。失败与取消后停止。缺失的旧记录显示不完整，不伪造零值。

### 3.5 质量与查看

**GR-V01：分别显示质量维度。** 显示几何连接、覆盖、画面、尺度和训练目标完成情况。训练导出不自动通过画面检查。几何、覆盖、画面及训练条件满足后，才汇总为完成；尺度另行展示，当前汇总不以实测尺度为必要条件。

**GR-V02：绑定画面检查。** 用户检查门口连接、重影、比例和覆盖。检查记录绑定当前尝试及几何签名。模型改变后，旧检查不能继续证明新模型合格。

**GR-V03：复用查看器。** 电脑使用键鼠；手机使用单指旋转、双指平移与缩放，以及移动按钮。查看器支持重置、切顶部和范围显示。这些操作不更改训练文件。

**GR-V04：明确在线条件。** 手机高斯查看依赖电脑在线。原生 APP 本地网格查看可离线。未校准照片场景中的移动速度和裁剪数值不能解释为真实米制测量。

## 4. 非功能要求

- **GR-N01 数据可追溯**：保存输入来源、清单、回答修订、尝试和几何签名。错误结果不能覆盖历史证据。
- **GR-N02 授权隔离**：手机只访问自己获授权的项目。异步读取或校验后，在关键写入和启动前重新检查设备权限。
- **GR-N03 存储边界**：文件名和存储路径由服务器控制。扫描包校验路径、大小、类型、清单和哈希。客户端不得指定输出路径。
- **GR-N04 可恢复性**：保留已完成上传、导入记录和删除记录。重启恢复不得将撤销设备重新授权。外部计算中断后允许人工重试。
- **GR-N05 资源限制**：全局同时运行一个重建作业；阶段有超时。网页照片列表限制 DOM 和缩略图数量；原生采集限制在途关键帧。
- **GR-N06 可解释性**：显示实际阶段和可操作的失败原因。手机响应不暴露电脑文件系统路径。性能估计与已测指标分开。
- **GR-N07 网络边界**：桌面保留本机监听，手机仅使用独立网关。默认 HTTP 不加密，仅用于可信局域网。
