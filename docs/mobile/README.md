# 手机照片重建与 LiDAR 扫描

## iPhone 与安卓网页

此方式无需安装原生 APP，也无需 Mac。iPhone 使用 Safari，安卓使用 Chrome。手机采集照片，Windows 完成重建。手机须连接电脑所在的局域网。

1. 启动 Windows 工作台。在左侧展开 **手机照片重建与 LiDAR 导入**，点击 **启用连接**。
2. 在手机打开显示的网页地址，例如 `http://192.168.1.10:8124/mobile/`。地址使用电脑的局域网 IP。不要在手机填写 `127.0.0.1`。
3. 输入配对码和设备名称。配对码五分钟后失效，使用一次后失效。页面在当前电脑地址下保存配对信息。
4. 输入项目名称，选择训练档位并创建批次。默认使用 **标准（standard）**。
5. 点击 **拍照**，或点击 **选择相册** 批量选图。如果浏览器不能打开相机，先用系统相机拍照，再选择照片。拍照使用标准[文件采集控件](https://www.w3.org/TR/html-media-capture/)。
6. 等待逐张上传。页面显示当前照片的字节进度、文件状态和失败原因。失败后点击 **重试**；也可移除失败项。
7. 照片全部就绪后，点击 **提交照片并创建项目**。创建项目后，再点击 **开始重建**。上传不会自动启动计算。
8. 查看阶段、进度、累计耗时和质量状态。电脑正忙时，等待当前作业结束后重试。场景生成后点击 **打开模型**。

连接默认关闭。Windows 工作台继续只监听本机地址。手机网关默认端口是 8124。用完可关闭连接，或在电脑撤销某台设备。设备只能访问自己的批次和项目。

### 照片限制与恢复

- 单张最多 64 MiB，每批最多 500 张、4 GiB。每张照片长边至少为 1000 像素。
- 至少需要两张内容不同的有效照片。重复内容不计入有效数量；同名文件可以上传。达到最低数量只表示可以提交，不保证几何检查或训练通过。
- JPEG 和 PNG 始终可用。只有电脑实际解码 HEIC 样本成功后，页面才开放 HEIC/HEIF。每张上传照片仍单独检查。浏览器无法选择 HEIC 时，请先将照片转为 JPEG 或 PNG。
- 原始上传字节及 EXIF 保存在新项目的 `source-images/`。手机缩略图不改变上传原件。
- 网络中断后，只需重新上传当前照片。已经完成的照片保留。刷新或重新打开网页后，选择原批次；未上传的照片须重新选择或移除。浏览器不保存照片文件。
- 存在待上传、上传中或失败的照片时，不能提交。提交中断后，可以重试创建项目。重复提交返回同一个项目。

普通照片使用现有 COLMAP、几何检查、去畸变和 Brush 流程。原有尝试记录、质量状态和累计计时继续保留。普通照片没有 LiDAR 米制标定，尺度显示 **未实测**。查看高斯场景时，电脑须在线。

接口见 [通用照片协议](photos-protocol.md)。Windows 检查记录和待验收项见 [通用照片验证记录](../validation/2026-11-03-mobile-photos.md)。iPhone Safari 与安卓 Chrome 的实机验收尚未完成。

## 原生 iPhone LiDAR APP

本次交付原生 APP 源码、Xcode 工程和 Windows 工作台接口。当前没有 Mac。iOS 编译、签名、XCTest 和 LiDAR 实机验收尚未执行。

## 手机使用

1. 按 [Mac 构建说明](../../apps/ios/README.md) 打开 Xcode 工程，选择签名团队，并安装到支持 LiDAR 的 iPhone。
2. 允许相机访问。开始扫描后缓慢移动，覆盖房间和门口。相邻房间须在同一次扫描中完成。
3. 可暂停并继续。停止保存后，在项目列表打开模型。严重发热或存储不足时，APP 暂停采集并保留已保存帧。
4. 生成彩色模型后可旋转查看。点选两个表面点来估算距离。输入最小和最大世界坐标可裁剪范围；撤销可恢复原网格。裁剪保留范围内的完整三角面，不修改原始 RGBD。
5. 导出 OBJ ZIP 供其他三维工具使用。完整扫描包另存为 `<扫描 UUID>.gaussroom.zip`。至少需要两张内容不同的关键帧。

没有可靠图像的表面保留中性色。测距使用 LiDAR 米制坐标，属于估算。电脑质量报告仍显示实际尺度未实测。

## 传到 Windows

1. 启动现有工作台。左侧展开 **手机照片重建与 LiDAR 导入**。
2. 点击 **启用连接**。在 APP 的连接页填写局域网地址和配对码。默认网关端口为 8124；配对码五分钟后失效，用过后失效。
3. 在 APP 选择刚导出的完整扫描包并上传。需要保留本机对应扫描。中断后再次选择同一个文件，可从服务器确认的偏移继续。
4. 上传完成后点击 **开始增强**。默认 standard 档位。APP 显示阶段、进度、累计耗时和质量状态。电脑已有作业时，等待其结束再启动。
5. 电脑生成高斯场景后，在 APP 打开查看器。单指旋转、双指平移或捏合缩放，箭头用于移动。此查看器要求电脑在线。

也可将 `.gaussroom.zip` 手动复制到电脑，在工作台填写扫描包绝对路径并点击 **导入扫描包**。两种导入使用同一校验器。重复导入同一个扫描包返回已有项目；同一 ID 的不同包不能覆盖旧项目。

连接默认关闭。用完可点击 **关闭连接**，或对已配对设备点击 **撤销**。原工作台仍只监听本机回环地址。网关只允许已配对设备访问其授权扫描项目。

## 重建规则

手机原始扫描保存到新项目内的 `capture/`。预处理保留图像对应关系，并按工作图片尺寸缩放逐帧内参。手机位姿固定后进行真实匹配轨迹三角化和点优化。原有注册率、重投影误差、点数及连通性门槛保持不变。

位置或连接错误时，保留报告和旧模型。请在手机补扫并导入新包。手机项目不能通过普通照片导入或无约束人工求解修改其标定。仅覆盖确认仍可使用现有流程。

## 验证边界

Windows 自动检查覆盖安全解包、哈希、同帧数据、内参和坐标转换、真实 pycolmap 数据库、上传恢复、项目权限和旧项目回归。合成几何测试包含 6,400 组对应点，使用原始阈值通过连通性检查，并实际调用 COLMAP 去畸变。它不是实拍照片的重建质量证明，也没有运行 Brush 训练。

Mac 和真机验收须检查：编译与 XCTest、单房间及连通双房间扫描、转屏、暂停继续、后台和中断、存储压力、重复导出、彩色和灰色 OBJ、估算距离误差、断网续传、任务轮询、WKWebView 模块及模型授权。真实扫描、纹理质量、设备性能和完整高斯漫游尚未验收。
