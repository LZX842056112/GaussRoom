# GaussRoom iPhone LiDAR APP

用户已于 2026-11-01 确认此设计并要求实施。

- 原生 SwiftUI、ARKit、RealityKit，iOS 17+，面向带 LiDAR 的 iPhone。
- 手机离线生成彩色网格；提供本地项目、扫描、查看、可撤销裁剪、估算测距、OBJ/MTL/纹理 ZIP 和完整扫描包导出。
- 相邻房间在同一次 AR 会话内连续扫描。世界坐标重置时结束当前扫描。
- 同帧记录 RGB、深度、置信度、内参和位姿。后台有界写盘，异常保留数据。纹理通过真实关键帧投影和遮挡检查生成。
- 独立、默认关闭的局域网网关支持配对、撤销、断点上传、离线导入和任务启动。不能开放原工作台的全部接口。
- 手机项目使用真实图像匹配和 ARKit 相机位姿三角化，保留现有几何门禁、尝试历史、质量状态和累计计时。
- 电脑使用完整原始扫描。手机裁剪只修改网格副本。
- APP 内用 WKWebView 联机查看现有高斯场景；增加触控，保留桌面键鼠。
- 默认训练 standard。用户主动启动电脑增强；占用时显示忙，不新增作业队列。
- 当前只有 Windows 和 LiDAR iPhone：交付源码、Xcode 工程、电脑端验证和 Mac 构建说明。iOS 编译、签名、真机验收必须明确列为待验收。
- 不包含 Android、TrueDepth 小物体、RoomPlan、跨会话拼接、原生离线高斯查看、云 Mac、IPA 或 App Store 发布。

考虑过 Flutter 加原生模块，以及手机只采集、电脑完成全部重建的方式。用户选择原生 iOS，并要求手机成模与电脑增强两条路径。

数据与接口的共同约束见 [protocol.md](../../mobile/protocol.md)。
