启用网页相机

网页相机需要 HTTPS。首次使用时，必须在手机上安装并信任本机证书。浏览器不能自动完成此步骤。

安装证书

先核对电脑显示的证书指纹。iPhone：下载描述文件，在“设置 → 通用 → VPN 与设备管理”安装。再到“通用 → 关于本机 → 证书信任设置”开启完全信任。Android：下载 CA 证书，在“设置 → 安全 → 加密与凭据”中安装 CA。不同系统的菜单名称可能不同。

只在你管理的电脑上使用此证书。完成信任设置后，点“转到 HTTPS”。相册和系统相机仍可使用。

采集提示

缓慢移动。相邻照片保留约 70% 的重叠区域。在门口向两个房间分别拍摄。使用高、中、低三个高度。原地改变朝向后，可以继续采集。

避开纯色墙面、强反光和移动物体。若画面纹理不足，重复检测不能给出可靠结论。手动补拍会跳过重复检测。

页面进入后台时会暂停。回到前台后，请点“继续采集”。请保留本页，直到本地待上传数量为 0。浏览器清除网站数据会丢失本地照片。
